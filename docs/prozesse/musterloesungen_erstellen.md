# Prozess – Musterlösungen erstellen

Diese Checkliste ergänzt [AGENTS.md](../../AGENTS.md). Die Repo-Regeln bleiben verbindlich.

## Checkliste

1. Zugehörige Übung vollständig lesen.
2. Genau eine Standardlösung liefern, wenn das Lernziel eindeutig ist.
3. Lösung kompakt halten.
4. Bei Java-Code keine unnötige Abstraktion einbauen.
5. Wichtige Zwischenschritte zeigen, aber nicht übererklären.
6. Typische Fehler kurz benennen, wenn sie didaktisch helfen.
7. Tabellen nur verwenden, wenn sie keine falschen Gegenüberstellungen erzeugen.
8. Codeblöcke korrekt auszeichnen.
9. Falls möglich, Java- oder Maven-Beispiele technisch prüfen.

## Qualitätsfragen

- Kann eine lernende Person die Lösung mit vertretbarem Aufwand nachvollziehen?
- Passt die Lösung direkt zur Aufgabenstellung?
- Bleibt die Lösung fachlich korrekt und auf EFZ-Niveau?
