# Skill – Java und Maven validieren

## Zweck

Unterstützt beim technischen Prüfen von Java- und Maven-Beispielen.

## Verwenden wenn

Java-Code, Package-Strukturen, Classpath-Beispiele oder Maven-Projekte technisch geprüft werden sollen.

## Vorgehen

1. Lies zuerst [AGENTS.md](../../../AGENTS.md).
2. Kläre, ob ein Maven-Projekt oder ein manuelles Java-Beispiel vorliegt.
3. Verwende für Maven-Projekte bevorzugt `mvn`.
4. Verwende `javac` nur zum Kompilieren von Java-Code.
5. Verwende `java` nur zum Ausführen erzeugter Artefakte.
6. Prüfe Package-Deklarationen gegen Ordnerstrukturen.
7. Prüfe Classpath oder Maven-Ausgabeordner passend zum Beispiel.
8. Dokumentiere nicht ausgeführte Prüfungen offen.

## Ergebnis

Eine knappe Validierung mit ausgeführten Befehlen, Ergebnis und allfälligen Einschränkungen.
