# Skill – Musterlösungen erstellen

## Zweck

Unterstützt beim Erstellen kompakter Musterlösungen zu Übungen.

## Verwenden wenn

Zu bestehenden Übungen eine Musterlösung erstellt oder fachlich/didaktisch geprüft werden soll.

## Vorgehen

1. Lies zuerst [AGENTS.md](../../../AGENTS.md).
2. Lies die zugehörige Übung vollständig.
3. Nutze [Prozess – Musterlösungen erstellen](../../../docs/prozesse/musterloesungen_erstellen.md).
4. Liefere eine direkte Standardlösung, wenn das Lernziel eindeutig ist.
5. Halte Java-Code klein und nachvollziehbar.
6. Ergänze kurze Fehlerhinweise nur dort, wo sie helfen.
7. Verifiziere Code technisch, wenn das praktikabel ist.

## Ergebnis

Eine kompakte, fachlich korrekte und lernendengerechte Musterlösung.
